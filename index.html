P Paper Trail
All tools Source ↗

a small, honest PDF toolbox

Every file stays
on your machine.

No uploads, no accounts, no server. Every tool below runs entirely in your browser and works offline once the page has loaded.

01

Merge PDF

Combine several PDFs into one, in whatever order you drag them.

 02

Split PDF

Pull out a page range, or explode every page into its own file.

 03

Organize pages

Reorder, rotate, and delete pages on a thumbnail board.

 04

Edit text

Click straight on existing text to retype it, in place.

 05

Add text & sign

Drop new text boxes anywhere, or draw a signature to place.

 06

Watermark

Stamp a diagonal (or straight) text watermark across every page.

 07

Page numbers

Number every page, starting wherever you like.

 08

PDF → Images

Export every page as a PNG or JPG, zipped up.

 09

Images → PDF

Turn a stack of photos or scans into one PDF.

Looking for OCR, PDF↔Word/Excel conversion, or password protection? Those need real server-side engines and aren't in this static toolbox — see the README for why, and what to add if you need them.
